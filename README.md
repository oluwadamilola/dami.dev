# Damilola Olukoju — Portfolio

A React, TypeScript and Vite portfolio for Damilola Olukoju, with an editorial visual system, responsive project showcases, architecture-diagram previews and reduced-motion-aware animation.

## Run locally

```sh
npm install
npm run dev
```

## Validate and build

```sh
npm run lint
npm run build
```

## Structure

- `src/components/` — shared visual components and icons
- `src/sections/` — portfolio page sections
- `src/data/` — typed project content
- `src/hooks/` — animation and pointer-interaction hooks
- `src/App.css` and `src/index.css` — component styles and design tokens

GSAP and ScrollTrigger provide entrance and scroll reveals; Motion for React provides the mobile navigation transition. Both respect the reduced-motion preference. The visual system uses CSS and HTML mockups rather than remote project imagery.
